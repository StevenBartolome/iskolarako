# IskoAko Monorepo

Welcome to the **IskoAko** repository! This workspace is split into two primary applications:

## Directory Structure

```
iskoako/
├── mobile/    # Flutter Mobile Application (Android, iOS, etc.)
└── web/       # React JS Web Application (built with Vite + TypeScript)
```

## Mobile App (Flutter)

Located in `./mobile`

### Quick Start
```bash
cd mobile
flutter pub get
flutter run
```

## Web App (React + Vite + TypeScript)

Located in `./web`

### Quick Start
```bash
cd web
npm install
npm run dev
```
